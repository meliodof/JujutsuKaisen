# АИС диспетчеризации автобусного парка

Информационная система для автобусного парка: учёт транспорта и водителей, маршруты и расписание, назначение рейсов, путевые листы, предрейсовые медосмотры и техосмотры. Выполнена в рамках лабораторных работ.

## Роли и возможности

| Роль | Что может |
|---|---|
| Администратор | Справочники ТС, моделей, водителей, остановок и маршрутов; шаблоны расписания; пользователи и роли; журнал операций |
| Диспетчер | Назначение и переназначение рейсов, контроль готовности (медосмотр, техосмотр, путевой лист), путевые листы, контроль пробега и топлива, уведомления в реальном времени |
| Водитель | Личный кабинет с расписанием рейсов на сегодня, отметка начала и завершения рейса с пробегом |
| Медик | Предрейсовые и послерейсовые медосмотры водителей |
| Механик | Техосмотры ТС, заправки и пробег, контроль сроков ТО |

Особенности:

- Проверка пересечения рейсов по времени: одного водителя или автобус нельзя назначить на два рейса одновременно (хранимые процедуры `trip_assign_safe`, `trip_reassign`)
- Автоматический расчёт длины и времени маршрута по остановкам
- Отслеживание интервала ТО по пробегу и уведомления диспетчеру через Server-Sent Events
- Журнал всех операций пользователей
- Пароли хранятся в виде BCrypt-хешей

## Технологии

- Java 24, Spring Boot 4
- Spring MVC, Spring Security (BCrypt), JdbcTemplate
- PostgreSQL: хранимые процедуры, функции, триггеры
- Thymeleaf, JavaScript (fetch API, SSE), CSS
- Lombok, Maven

## База данных

Основные таблицы: `vehicle`, `vehicle_model`, `driver`, `route`, `stop`, `route_stop_order`, `schedule_template`, `trip_assignment`, `waybill`, `medical_check`, `vehicle_inspection`, `fuel_log`, `vehicle_maintenance`, `dispatcher_notification`, `operation_log`, `app_user`, `app_role`.

Скрипт `db/jujutsukaisen_db.sql` создаёт схему, процедуры и функции и заполняет базу демонстрационными данными по маршрутам Самары. Даты рейсов считаются от текущего дня.

## Запуск

1. Создайте в PostgreSQL базу `JujutsuKaisen` и выполните в ней `db/jujutsukaisen_db.sql`.
2. Укажите логин и пароль к БД в `src/main/resources/application.properties`.
3. Запустите приложение:
   ```bash
   mvn spring-boot:run
   ```
4. Откройте http://localhost:8080

Демо-учётные записи:

| Логин | Пароль | Роль |
|---|---|---|
| `admin` | `admin123` | Администратор |
| `dispatcher` | `disp123` | Диспетчер |
| `medic` | `medic123` | Медик |
| `mechanic` | `mech123` | Механик |
| `ivanov` | `driver123` | Водитель |
